# 哈太郎首爾美食朝聖指南：黑白大廚篇

Vue 3 + Vite 原始碼。建置結果會輸出到儲存庫根目錄的 `hataroSeoulFoodGuide/`，可直接由 GitHub Pages 提供。

## 目錄分工

- `data-source/`：餐廳 JSON、資料結構、來源備註及人工校對資料。
- `src/`：網站畫面、互動、篩選與本機收藏功能。
- `../../hataroSeoulFoodGuide/`：執行正式建置後產生的靜態網站。

網站執行與建置均不依賴儲存庫根目錄的 `temp/`。

## 本機指令

```sh
npm install
npm run dev
npm run build
npm run preview
```
