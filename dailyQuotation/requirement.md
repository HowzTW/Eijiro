# 每日箴言 Web App 系統需求與設計文件

## 1. 專案概述
本專案旨在重新設計「每日箴言」的網頁介面，提供一個簡潔、直覺且具備現代感的使用者體驗，方便使用者閱讀每日金句。

## 2. 介面結構設計 (UI Structure)

系統介面分為四個核心區塊：

### 2.1 頁首區塊 (Header Block)
*   **特性**：**固定 (Sticky)** 於畫面最上方，不隨頁面捲動消失。
*   **內容元件**：
    *   **標誌 (Icon)**：顯示應用程式圖示。
    *   **標題 (Title)**：顯示「每日箴言」。
*   **視覺要求**：需具備高對比度及清晰度，確保導航功能始終可用。

### 2.2 日期選擇區塊 (Date Picker Block)
*   **特性**：**可捲動 (Scrollable)** 內容的一部分。
*   **功能要求**：
    *   **預設日期**：畫面載入時自動設定為本地當天日期。
    *   **日期選擇器**：允許使用者自由選擇特定日期。
    *   **導覽按鈕**：提供「前一日」與「後一日」按鈕，快速切換日期。
*   **互動邏輯**：切換日期時，下方的內容區塊需同步更新。

### 2.3 內容顯示區塊 (Content Block)
*   **特性**：**可捲動 (Scrollable)**。
*   **顯示內容**：從 `data-cht.json` 抓取對應日期的金句內容（多行文字方塊）、出處（單行文字方塊）及背景資訊（單行文字方塊）。

### 2.4 頁尾區塊 (Footer Block)
*   **特性**：**固定 (Sticky)** 於畫面最下方，不隨頁面捲動移動。
*   **功能內容**：
    *   **最後修改時間**：顯示 `index.html` 檔案的最後修改時間。
    *   **時間格式**：台灣時間 (UTC+8)，格式為 `YYYY-MM-DD HH:mm:ss` (例如：`2026-03-03 18:22:18`)。
*   **技術實現**：透過腳本讀取檔案元數據或佈署環境變數來動態呈現。

## 3. 技術規格需求
*   **前端架構**：HTML5, CSS3 (Vanilla CSS), JavaScript。
*   **資料來源**：`data-cht.json`。
*   **排版技術**：Flexbox 或 Grid 佈局以實現響應式設計（Responsive Design）。
*   **檔案同步**：確保 CSS 及 JS 引用路徑正確，適合本地伺服器執行。
