# 阿玉金嗓歌單 (Ayu Songbook) 系統設計規格書

## 1. 專案概述
「阿玉金嗓歌單 (Ayu Songbook)」是一款專為年長者設計的響應式網頁應用。主要功能是提供易於讀取與操作的歌單內容，讓使用者能搜尋歌曲並管理個人金嗓歌單，適用於手機與電腦不同螢幕尺寸。

## 2. 目標使用者
- **年長者群體**：注重視覺易讀性，操作介面需簡潔且直覺。
- **手機使用者**：在行動裝置上的閱讀體驗需優化，按鈕與文字需夠大。

## 3. 設計原則 (UI/UX)
- **視覺呈現**：
    - 使用大尺寸且加粗的文字，方便老花眼年長者閱讀。
    - 對比度需足夠鮮明，避免過於複雜的背景干擾。
    - 彈出視窗採用**自定義組件**而非系統預設視窗，確保文字字級足夠大。
    - 使用 **Google Material Icons** (Google 提供的免費圖示字體) 作為 UI 圖示。
    - **設計指導方針**：整體視覺與排版必須嚴格遵循 **[DESIGN.md](file:///Users/Howz/文件/Eijiro/ayuSongbook/DESIGN.md)** 中定義的「黃金時代編輯感 (Golden Era Editorial)」風格，包含無邊框規則、層次化佈局與 Manrope 字體比例。
- **動態效果**：
    - 區塊切換（如搜尋結果）需具備流暢的展開與收合動畫。
- **響應式配置**：
    - Header 固定於頂部。
    - 適配各類螢幕，保持排版工整。

## 4. 功能需求 - 歡迎畫面 (Splash Screen)
在應用程式載入時首先顯示的進入畫面。

### 視覺元素
- **LOGO**：正中央顯示正方形標識圖示 (`icon.png`)，具備呼吸感動畫。
- **應用名稱**：主標題「阿玉金嗓歌單」，副標題「Ayu Songbook」，具備漸層立體文字效果。
- **更新資訊**：底部顯示「最後更新時間：yyyy-mm-dd hh:mm:ss」，自動讀取檔案修改時間。

### 互動與轉換邏輯
- 進入應用後停留 4 秒或點擊畫面任何位置，即淡出並切換至主畫面。

## 5. 功能需求 - 主畫面 (Main Screen)

### (1) 頂部橫幅 (Header Block)
- **內容**：小型 LOGO 與應用中文名稱「阿玉金嗓歌單」。
- **行為**：固定在版面上方 (Sticky/Fixed)，捲動頁面時不會消失。

### (2) 搜尋區塊 (Search Block)
- **初始狀態**：載入即顯示。
- **元件**：
    - **搜尋框 (Textbox)**：輸入搜尋關鍵字。
        - **便捷清除機制**：搜尋框內需提供快速清除文字的機制（如內嵌的清除圖示），方便使用者一鍵清空輸入內容。
    - **執行搜尋按鈕**：
        - 檢查邏輯：若搜尋框為空或僅有空白字元，按鈕變更為 `disabled` 狀態。
        - 行為：點擊後執行搜尋（串接資料庫），並將結果顯示於「搜尋結果區塊」。

### (3) 搜尋結果區塊 (Search Results Block)
- **初始狀態**：隱藏。
- **觸發條件**：完成搜尋後以「動畫展開」形式呈現。
- **資料來源與處理邏輯 (外部搜尋)**：
    - **前端預處理**：自動將搜尋框內的字串文字移除所有空白字元。
    - **抓取機制**：由於跨網域限制 (CORS)，將關鍵字發送至 **GAS 端**，由 GAS 使用 `UrlFetchApp` 讀取外部網站 `https://song.corp.com.tw/songs.aspx?company=%E9%87%91%E5%97%93&keyword=[關鍵字]`。
    - **解析邏輯**：在 GAS 端解析 HTML 內容，從 `<ul class="data-list">` 的 `<li>` 中提取以下欄位：
        - 歌名：`<div class="name">` 內容。
        - 演唱人：`<div class="singer">` 內容。
        - 歌曲編號：`<div class="code">` 內容。
        - 備註：`<div class="lang">` 內容（例如：台 / 金嗓）。
- **顯示邏輯**：
    - 若無結果：檢查是否存在 `<div class="mescroll-empty">`，若有則顯示「查無結果」。
    - 若有結果：每筆資料顯示上述四個欄位。
- **互動**：
    - **「＋」按鈕**：
        - 點擊後彈出大型自定義確認視窗。
        - 確認後透過 GAS 將資料存入 Google 試算表資料庫。
    - **收合按鈕 (原清除按鈕)**：位於區塊內，點擊後以「動畫收合」形式隱藏本區塊。

### (4) 歌單區塊 (Songlist Block)
- **初始狀態**：載入即顯示。
- **資料來源**：透過 GAS 讀取 Google 試算表。
- **例外處理**：
    - 若無資料：顯示「目前歌單沒有資料」。
    - 若讀取失敗：顯示「歌單資料讀取失敗」。
- **顯示內容**：歌名、演唱人、歌曲編號、備註。
- **排序與分群邏輯**：
    - **第一層**：依歌名字數長短分群（短字數在前）。
    - **第二層**：同字數群組內，依歌名排序（如筆畫或英文字母）。
- **互動**：
    - **「－」按鈕**：
        - 點擊後彈出大型自定義確認視窗。
        - 確認後透過 GAS 從試算表刪除，並即時從 UI 移除該筆顯示。

### (5) 頁尾區塊 (Footer Block)
- **內容**：顯示「最後更新日期：yyyy-mm-dd hh:mm:ss」。
- **邏輯**：自動讀取 `index.html` 的最後修改時間。

## 6. 技術架構
- **前端**：HTML5, Vanilla CSS, JavaScript (ES6+)。
- **後端資料庫**：Google Sheets (透過 Google Apps Script API 存取)。
- **動畫庫**：CSS Transitions / Web Animations API。
