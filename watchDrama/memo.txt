要做一個 web app，叫做「追劇小幫手」，只用 html css js 開發，可以部署在 Github Pages。

這個 web app 的功能是：讓使用者可以透過這個網頁追劇。不同使用者會看到各自的內容。
1. 功能一：要有一個方便的方式切換不同使用者(userId, userName)，要用 localStorage 記住上一次選取的使用者。
2. 功能二：使用者可以從所有劇集資料庫中，挑選新增或移除要追的劇。可供挑選的劇集資訊要從 GAS-1 讀取。這個 web app 只記錄使用者所挑選的劇集 id，劇集本身所有的資訊都要從 GAS-1 讀取。 
3. 功能三：程式進入點，是列示使用者挑選要追的劇（顯示封面圖片及片名），要依最後曾經觀看的劇排在最前面。而且使用者可以在此功能頁面移除某部要追的劇。
4. 功能四：使用者點擊某部劇的封面圖片，會進入該劇的播放頁面。播放頁面會列出所有線路的集數，而且該部劇集最後一次播放的線路的該集數，必須 high light 顯示。使用者可以點擊某集進行播放。播放頁面要顯示封面圖片及片名、劇情介紹。
5. 功能五：播放頁面要顯示播放器，播放器要能播放 .m3u8 影片。播放器要能播放 .m3u8 影片。

GAS-1: 讀取所有劇集資訊：  https://script.google.com/macros/s/AKfycbzwHa2fa4e_QdyfD3z01tXepwY9ZyY98UlS_6mjVGOsPZaoHVloSyEc9_kJniuNn2_X/exec 
這個GAS會讀取一個 Google Sheet 文件，欄位包括：ID / 片名 / 劇情介紹 / 封面圖片 / 更新時間 / 線路資料（JSON）。
而線路資料(JSON)的結構中記錄的資訊包括：
line_name (線路名稱)：記錄該播放來源的名字（如：南亞線路、OK線路、閃電線路）。
episodes (集數陣列)：此線路下所有的集數列表。
name (集數名稱)：例如「第01集」、「第02集」。
playPageUrl (播放頁連結)：777TV 網站上原始的播放頁面網址。
play_url (真正的影片網址)：這是最重要的部分。它是程式從後端抓出來的 .m3u8 直連網址。有了這個網址，理論上您可以直接用任何支援 HLS 的播放器觀看。

GAS-2: 這個 web app 所需要記錄存取的資料庫，要在這個專案新建一個 GAS。
