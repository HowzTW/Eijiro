# 「追劇小幫手」系統開發需求規格書 (Requirement Specification)

## 1. 專案簡介
本專案名為「追劇小幫手」(Watch Drama Assistant)，是一個純前端開發的 Web 應用程式。其目的是為使用者提供一個個人化的追劇平台，能夠串接由「抓劇小幫手」抓取的劇集資料庫，並記錄使用者的觀看進度。

## 2. 技術規格
- **開發語言**: 純 HTML, CSS, JavaScript (Vanilla JS)。
- **部署平台**: 可直接部署於 GitHub Pages 等靜態網站託管服務。
- **資料存儲**:
  - 本地端：使用 `localStorage` 存儲使用者身份、最後觀看記錄及偏好設定。
  - 雲端端：
    - **GAS-1**: 讀取由抓劇程式產生的全域劇集資料庫。
    - **GAS-2**: 新建專門用於存取各個使用者「自訂劇單」、「觀看狀態」及「詳細播放進度」的資料庫。
- **離線與安裝**: 支援 PWA (Progressive Web App)，可安裝至手機/電腦桌面。

## 3. 功能需求

### 3.1 使用者管理 (User Management)
- 提供方便的介面供不同使用者切換設定 (userId, userName)。
- 系統須能個別分辨不同使用者的追劇內容與進度。
- **持久化與引導設計**:
  - 使用 `localStorage` 記憶最後一次選取的使用者身份，再次開啟網頁時免重複選取並自動登錄。
  - 若 `localStorage` 中無最後一次選取的使用者身份，則自動顯示使用者列表供選擇。

### 3.2 劇集挑選與管理 (Library Management)
- 使用者可瀏覽所有「全域劇集資料庫 (GAS-1)」中的內容。
- 提供「新增至追劇」與「移除」的功能。
- **資料分離原則**:
  - 此 Web App 本身不存儲劇集詳細資訊，僅在使用者資料庫 (GAS-2) 記錄使用者挑選的 `dramaId`。
  - 劇集之封面、標題、線路等詳細資訊皆於執行時動態從 GAS-1 讀取。

### 3.3 個人追劇畫面 (Personal Dashboard)
- **進入點**: 應用程式啟動的首頁為使用者的個人追劇清單。
- **顯示資訊**: 顯示劇集封面、片名。
- **排序邏輯**: 依據「最後觀看時間」降冪排列（最近看的排在最前面），確保使用者能快速繼續進度。
- **管理功能**: 使用者可在首頁直接移除不再追蹤的劇集。

### 3.4 劇集播放頁面 (Playback Page)
- **詳細資訊**: 顯示劇集封面、片名及劇情介紹。
- **播放進度狀態**: 醒目地標示出該劇集最後一次播放的線路名稱與集數。
- **播放按鈕群**:
  1. **播放按鈕**: 點擊後立即播放目前選取（或上次中斷）的線路與集數。
  2. **上一集按鈕**: 點擊後切換並播放目前選取線路的前一集。
  3. **下一集按鈕**: 點擊後切換並播放目前選取線路的後一集。
- **線路與集數選取**:
  - **線路清單**: 列出該劇集所有可用的播放線路，並高亮 (Highlight) 顯示最後一次播放的線路。
  - **集數清單**: 以按鈕格式顯示該線路下的所有集數，高亮顯示最後一次播放的集數。點擊任一集數按鈕即重新載入該集之 `.m3u8` 並開始播放。
- **自動化功能**:
  - **續播功能**: 自動從上次中斷的秒數 (Timestamp) 繼續播放。
  - **自動連播**: 當該集結束時，自動切換至下一集播放。

### 3.5 影音播放器 (Video Player)
- 整合支援 HLS (HTTP Live Streaming) 協議的播放器。
- 必須能夠流暢播放 `.m3u8` 格式的影片來源。

## 4. 資料介面 (API)

### 4.1 全域劇集資料 (GAS-1)

- **欄位說明**:
  - `ID`: 劇集編號
  - `片名`: 劇集名稱
  - `劇情介紹`: 詳細故事描述
  - `封面圖片`: 圖片網址
  - `更新時間`: 資料庫同步時間
  - `線路資料 (JSON)`: 包含 `line_name` (線路名)、`episodes` (集數陣列，內含 `name`、`playPageUrl`、`play_url`)。

### 4.2 使用者私有庫 (GAS-2)
- **用途**: 記錄各使用者挑選的 `dramaId` 及其播放歷史記錄。
- **開發任務**: 需在此專案中新建對應的 GAS 與 Google Sheet 結構。
